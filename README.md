# Mohanad Portfolio

A static, responsive portfolio site for [Mohanad Galmad](https://github.com/hondagalmad).

## Preview locally

Open `index.html` in a browser, or serve this folder with any static web server.

## Profile README

The GitHub profile README is ready in [`profile-readme/README.md`](profile-readme/README.md). Create a public repository named **`hondagalmad`** (exactly matching your GitHub username) and copy that file to the repository root as `README.md`.
